**Project Proposal**

**Project Title**

**Manual Test Plan & Bug Report Suite for an E-commerce Store**

**Introduction**

This project focuses on performing manual functional testing of an e-commerce website. The purpose is to verify that important features of the website work correctly and to identify and document any defects found during testing.

**Problem Statement**

E-commerce websites contain several important functions such as product browsing, cart management, and checkout. Functional issues in these areas can affect the user experience. Therefore, systematic manual testing is required to identify such issues before the product is considered reliable.

**Objectives**

- To perform manual functional testing of the e-commerce website.
- To verify important user functionalities.
- To identify and document software bugs.
- To maintain test cases and test execution results.
- To provide clear and organized testing documentation.

**Scope**

The testing covers:

- Product listing
- Product details
- Product price
- Add to Cart functionality
- Multiple products in Cart
- Cart refresh/persistence
- Checkout form validation
- Required field validation
- Cart quantity functionality

**Testing Methodology**

Manual functional testing will be performed by executing predefined test cases. Each test case will be marked as Passed, Failed, or Blocked based on the observed result. Identified defects will be documented with steps to reproduce, expected result, actual result, severity, and status.

**Tools Used**

- Jira
- GitHub
- Google Chrome
- E-commerce Demo Website

**Expected Deliverables**

- Manual Test Plan
- Test Cases
- Test Execution Report
- Bug Reports
- Testing Screenshots
- Project Documentation

**Expected Outcome**

The project will provide a structured manual testing suite for the e-commerce website and will identify functional issues that may affect users. The testing results and documented defects will help improve the quality and reliability of the website.

**Conclusion**

This project demonstrates the process of planning, executing, documenting, and reporting manual functional testing for an e-commerce application. The final repository will contain organized testing documentation, test results, bug reports, and supporting screenshots.
